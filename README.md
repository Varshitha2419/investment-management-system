A simple web-based system to manage investments, track portfolios, record transactions, and analyze profit/loss with an easy-to-use interface.

🚀 Features

Add, edit, delete investment assets

Track buy/sell transactions

Automatic profit/loss calculation

Portfolio performance overview

User login & secure session

Responsive and clean UI

🛠️ Tech Used

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL

Tools: XAMPP/WAMP, Git, GitHub

📂 Project Structure
Investment-Management-System/
│── assets/
│── database/
│── pages/
│── config.php
│── index.php
│── README.md

⚙️ How to Run

Clone or download the project.

Move it to: xampp/htdocs/

Create a database and import the SQL file from /database.

Update DB details in config.php.

Run in browser:

http://localhost/investment-management-system
